# Try to break Clove

Clove Build Lab is a free, open-source browser laboratory. One (now three) PEI dwellings. It is **not** a permit service.

We want you to attack it.

Frozen public release: **v0.2.0**  
Working depth branch: `v0.3-construction-depth`

## The challenge

Find **one** of:

1. **Physical reality failure** — “I would not actually build it like this.”
2. **Authority / evidence failure** — “Clove is claiming more than its evidence proves.”
3. **Usability failure** — “This taught me the wrong mental model,” or “I could not inspect it.”

Do not be polite. Tell us what is wrong.

## How to report

Open a GitHub issue using one of:

- [Physical reality failure](https://github.com/rbardyla-boop/clove-build/issues/new?template=physical-reality.yml)
- [Authority / evidence failure](https://github.com/rbardyla-boop/clove-build/issues/new?template=authority-evidence.yml)
- [Usability failure](https://github.com/rbardyla-boop/clove-build/issues/new?template=usability.yml)

Include:

- component / area
- what you expected
- what Clove showed
- why it appears wrong
- screenshot if you can
- trade / background optional

You do not need an account beyond GitHub’s normal issue process.
